# Contributing

1. Installa Python 3.13 e FFmpeg locale, oppure usa `start.bat` per il download automatico di FFmpeg.
2. Installa le dipendenze di sviluppo con `python -m pip install -r requirements.txt`.
3. Avvia l'app con `start.bat`.
4. Verifica le modifiche costruendo l'eseguibile con `build_exe.bat`.

Le modifiche devono mantenere intatti i file originali dell'utente e non devono
introdurre dipendenze o dati di telemetria non documentati.
